## 📌 Overview
A collection of 5 core Python implementations covering custom data structures, recursive algorithms, object-oriented inheritance, and system configuration management.

## 📂 Included Projects

### 1. [Tower of Hanoi Algorithm Solver](./tower_of_hanoi.py)
* Implemented a recursive algorithmic solver to compute and track optimal disk state transitions across three rods for $N$ disks in $2^N - 1$ moves.

### 2. [Custom Hash Table Implementation](./hash_table.py)
* Built a key-value Hash Table data structure from scratch in Python, implementing custom hashing logic, bucket storage, key lookup, insertion, and deletion methods.

### 3. [User Configuration Manager](./user_config_manager.py)
* Developed a configuration state utility capable of parsing, validating, updating, and managing user/system preference dictionaries cleanly.

### 4. [Polygon Area Calculator (OOP Inheritance)](./polygon_area_calculator.py)
* Engineered `Rectangle` and `Square` classes using Object-Oriented inheritance to compute area, perimeter, diagonal length, and geometric containment ratios.

### 5. [Object-Oriented Budget & Ledger App](./budget_app.py)
* Built a financial category ledger supporting deposits, withdrawals, inter-category fund transfers, balance validation, and dynamic ASCII percentage bar-chart generation.
